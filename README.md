# Lae Port Redevelopment PhotoMap

Combined Leaflet 2D photo map and Cesium 3D presentation tour for the Lae Port Redevelopment project.

Stakeholder page: <https://mcd2026.github.io/Lae-Port-Redevelopment/>

Routine photo updates can be uploaded to `incoming-photos`; GitHub Actions rebuilds and republishes the site automatically.

The stakeholder page is deployed from `github-pages` by the GitHub Pages workflow.
