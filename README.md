# PhotoMap

**NZP-TND-8288 | Lae Port Redevelopment**

Combined Leaflet 2D photo map and Cesium 3D presentation tour.

Stakeholder page: <https://mcd2026.github.io/Lae-Port-Redevelopment/>

Routine photo updates can be uploaded to `incoming-photos`; GitHub Actions rebuilds and republishes the site automatically.

The stakeholder page is deployed from `github-pages` by the GitHub Pages workflow.

Team instructions: [build, publish and update a PhotoMap](TEAM_PHOTOMAP_TUTORIAL.md).

Plain-language Word guide: [from a photo ZIP file to a shareable PhotoMap](PhotoMap_From_Photo_ZIP_to_GitHub_Website.docx).
